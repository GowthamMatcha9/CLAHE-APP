How this works
  • Tile grid divides the image into local regions, each equalized on its own.
  • Clip limit caps tall histogram bins so contrast and noise aren't over‑amplified.
  • Input intensity range — CLAHE is applied only within this range; values outside it pass through unchanged.
  • Colour images default to luminance mode, boosting contrast while preserving colour relationships.
